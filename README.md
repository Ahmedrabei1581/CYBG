# CYBG · سايبجي — ساحات معارك البرمجة والذكاء الاصطناعي

لعبة مغامرات وأكشن تعليمية ثنائية الأبعاد باللغة العربية (RTL)، مصممة وفق **منهج البرمجة والذكاء الاصطناعي للبكالوريا المصرية (الجزء الأول)**.

## المميزات الرئيسية (Key Features)

- **4 عوالم تعليمية متدرجة:**
  1. **مدينة الذكاء الاصطناعي** — تكنولوجيا المعلومات والمجتمع
  2. **القلعة السيبرانية** — الأمن السيبراني والدفاع الشبكي
  3. **عالم تطبيقات الويب** — بنية الويب والاتصال وتقنيات الواجهات
  4. **مملكة تجربة المستخدم** — تصميم الويب والوسائط والتحسين المستمر
- **20 مرحلة فرعية ومعارك زعماء:** 5 مراحل متصاعدة في كل عالم مع أبراج دفاعية، حواجز، عكس طلقات الليزر، وزعماء فريدين لكل عالم.
- **100 تحدي من المنهج الرسمي:** 25 سؤالاً في كل عالم مع شرح فوري للإجابات، وتشخيص الأخطاء، وبوابة إتقان **80% (20/25)** لفتح العالم التالي.
- **نظام دخول آمن واستكمال تلقائي:**
  - تسجيل من خطوتين للمستخدم الجديد (اسم فريد + رقم موبايل + كود تفعيل من 4 أرقام مع إرسال مباشر عبر **WhatsApp** أو **SMS** وكود احتياطي للعمل بدون إنترنت).
  - قائمة منسدلة بمستخدمي الجهاز للدخول برقم الموبايل واستكمال اللعب من آخر عالم ومرحلة، أو اختيار **بداية جديدة**.
- **تطبيق ويب تقدمي (PWA) يعمل بدون إنترنت:**
  - قابل للتثبيت بملء الشاشة على الهواتف والحواسيب.
  - يدعم اللمس المتعدد على الموبايل، ولوحة المفاتيح والماوس، وأذرع التحكم (Gamepad API).
- **لوحة تحليلات للمعلم والطالب:** متابعة نسب الإتقان، تشخيص نقاط الضعف، وتصدير تقارير الأداء بصيغة JSON.

## التقنيات المستخدمة (Tech Stack)

- **React 19** + **TypeScript**
- **Tailwind CSS v4**
- **Vite** + **vite-plugin-pwa**
- **HTML5 Canvas** (محرك الأكشن ثنائي الأبعاد) و **Web Audio API** (مؤثرات صوتية مدمجة)
